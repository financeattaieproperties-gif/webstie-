Place these icon files here before running `npm run pack`:

  icon.ico   — Windows app icon (256x256, multi-size ICO)
  icon.icns  — macOS app icon (512x512 ICNS)
  icon.png   — Linux app icon (512x512 PNG)

All three can be generated from a single 1024x1024 PNG using:
  https://www.electron.build/icons
